# AI Policy

## Overview
This document outlines the AI policy for contributing to the IL2LLVM project. The goal of this policy is to ensure that contributions made using AI tools are transparent.

## AI-Generated Contributions
Contributors are required to disclose when they have used AI tools to generate code, documentation, or other contributions to the project. This can be done by including a comment in the code or a note in the commit message indicating that AI was used. For example:
```csharp
// This code was generated using an AI tool.
...

// This part of the code was generated using an AI tool.
...
```
or in the commit message:
```
Added new feature X (AI-generated)
...
AI helped fix this bug by generating the following code:
...
```

## Guidelines for AI-Generated Contributions
1. **Usage**: A commit, pull request, or contribution cannot contain more than 25% AI-generated content. This is to ensure that the majority of the contribution is human-generated and that AI is used as a tool to assist rather than replace human creativity and judgment.
2. **Transparency**: Always disclose the use of AI tools in your contributions.
3. **Review**: AI-generated code should be reviewed by a human contributor to ensure it meets the project's standards for quality, security, and maintainability.
4. **Attribution**: If the AI tool used has specific attribution requirements, ensure that these are followed in accordance with the tool's license.
5. **Ethical Use**: Do not use AI tools to generate content that is unethical, harmful, or violates the project's code of conduct.
6. **Compliance**: Ensure that AI-generated contributions comply with the project's licensing and contribution guidelines.
7. **Feedback**: If you have suggestions for improving the AI policy or have concerns about AI-generated contributions, please open an issue or contact the project maintainers.

## Enforcement
Failure to comply with this AI policy may result in the rejection of contributions, removal of AI-generated content, or other actions as deemed appropriate by the project maintainers. The goal is to foster a collaborative and transparent environment while leveraging AI tools responsibly.

## Good Use of AI
AI tools can be used to assist with tasks in beneficial order:
1. **Reviewing**: AI has a strong suit in reviewing code for potential issues. It can be used to analyze code for security vulnerabilities, performance optimizations, and adherence to coding standards.
2. **Testing**: AI can be used to generate test cases, perform automated testing, and identify edge cases that may not have been considered by human contributors.
3. **Documentation**: AI can assist in generating documentation, such as code comments, API documentation, and user guides, based on the codebase and existing documentation.
4. **Refactoring**: AI can help identify areas of the code that could benefit from refactoring and suggest improvements to enhance readability, maintainability, and performance.
5. **Learning**: AI can be used as a learning tool to help contributors understand complex code, algorithms, or concepts by providing explanations and examples.

## Bad Use of AI
1. **Large-Scale Generation**: Using AI to generate large portions of code without human oversight can lead to issues with quality, security, and maintainability. It can also hinder the learning and growth of contributors.
2. **Lack of Transparency**: Failing to disclose the use of AI tools can create confusion and undermine trust within the community.
3. **Ethical Concerns**: Using AI to generate content that is unethical, harmful, or violates the project's code of conduct is strictly prohibited.
4. **Over-Reliance**: Relying too heavily on AI tools can stifle creativity and critical thinking among contributors. It's important to use AI as a tool to assist rather than replace human judgment.
5. **Ignoring Review**: Submitting AI-generated code without proper human review can lead to the introduction of bugs, security vulnerabilities, and other issues that could have been caught with a thorough review process.

## Abuse
If you believe that someone is abusing AI tools in their contributions or not following the AI policy, please report it to the project maintainers. Provide as much detail as possible, including links to the relevant contributions and any evidence of AI usage. The maintainers will investigate the issue and take appropriate action based on the findings.
